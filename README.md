# Fitness Formula — 40 Kunlik Tana Transformatsiyasi

Fitnes murabbiyi Sirojiddin Sharafovning rasmiy "Fitness Formula" veb-sayti.

## 📁 Loyiha tarkibi
- `index.html` — Asosiy HTML tuzilma
- `style.css` — Qorong'u gym dizayni (ko'k va oq neon ranglar bilan)
- `script.js` — Animatsiyalar, menyu va formani boshqarish
- `images/`
  - `logo.jpg` — FF Fitness Formula logotipi
  - `sirojiddin.jpg` — Sirojiddin Sharafov rasmi
- `video/`
  - `logo.mp4` — FF video logotipi

## 🚀 Vercel'da ishga tushirish (Deploy)
1. Ushbu papkani GitHub repozitoriyingizga yuklang (`git push` yoki GitHub orqali "Upload files").
2. [vercel.com](https://vercel.com) ga kiring.
3. **"Add New..."** -> **"Project"** ni tanlang.
4. GitHub repozitoriyangizni ulang va **"Deploy"** tugmasini bosing (hech qanday sozlash talab qilinmaydi, statik sayt avtomatik ishga tushadi).
